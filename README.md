# Sales-Prediction-and-Forecasting-Dashboard
Sales Prediction Dashboard (Power BI)

This project demonstrates a Sales Prediction Dashboard built in Power BI, designed to analyze historical sales data and forecast future revenue trends. The dashboard provides interactive insights that help identify growth opportunities and support data-driven decision-making.

Key Features:

Interactive Dashboard – Explore sales trends across time, regions, and product categories.

Sales Forecasting – Uses Power BI’s built-in forecasting models to predict future sales.

Dynamic Visualizations – Charts, KPIs, and slicers for better user interaction.

Data Modeling with DAX – Custom measures and calculations for accurate analysis.

Business Insights – Helps stakeholders understand patterns, seasonal demand, and potential growth areas.

Tools & Techniques:

Power BI Desktop

DAX (Data Analysis Expressions)

Data Cleaning & Transformation (Power Query)
